# 爵士鼓練習室（PWA）

練爵士鼓用的工具：跟著鼓譜數小節、節拍器練習。這個網站本身不含任何歌曲，歌曲由使用者匯入，只存在自己的裝置上。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個 App（曲庫＋練習畫面） |
| `sw.js` | 離線快取，改版時把裡面的 `VERSION` 加一 |
| `manifest.webmanifest`、`icon-*.png`、`apple-touch-icon.png` | 安裝到主畫面用的名稱和圖示 |
| `robots.txt` | 請搜尋引擎不要收錄 |

## 在 iPad / iPhone 安裝

1. 用 **Safari** 打開網站網址。
2. 按「分享 → 加入主畫面」。
3. 之後一律從主畫面的「爵士鼓」圖示打開。主畫面 App 和 Safari 分頁的資料是分開的，歌要在主畫面 App 裡匯入。
4. 按「＋ 匯入歌曲」，選 `make_bundle.py` 產生的 `.html` 打包檔（最方便），或 `.zip`，或 song.json＋音檔＋鼓譜。

第一次打開要連網，之後不連網也能用。

## 更新網站

改好 `index.html` 後，把 `sw.js` 裡的 `VERSION` 加一（例如 `cb-v2`），commit 並 push。使用者下次連網打開時就會更新。

## 已知限制

- 螢幕鎖定或切到別的 App 時，播放可能會停。這是 iOS 對網頁 App 的限制。
- 主畫面 App 的資料存在裝置上。長時間沒打開時，iOS 有可能清掉，所以打包檔請保留一份在「檔案」App 裡，可以隨時重新匯入。
